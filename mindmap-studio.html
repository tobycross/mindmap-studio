Open a map

    
Open a .mindmap.json file and the map comes back exactly as you left it. Markdown files work too. You can also drop a file anywhere on the page.

    

    
    
Or paste Markdown or any indented list. The first heading or top line becomes the centre topic, indentation sets the levels, and numbers at the start of lines are dropped.
